# Overview

Venworks Customizable HUD - Minimalist Theme uses the reduced VWHUD composition with pale-blue holographic presentation, no faction crest, and no equipment rail. It is an HTML/CSS/SVG consumer rendered by Venworks Canvas and retains its own plugin and compact status-effect catalog.

# Features

- Reduced compass, threat, status, player, environment, objective, radar, and scanner displays.
- Player health, oxygen, CO2, boost, carry mass, currency, time, and progression information.
- Acquired-contact radar in the upper-left composition.
- Compact paged status effects and Bethesda's current vehicle-exit glyph.

# Requirements and installation

Install Venworks Core Library version 2.1.8 or newer, then Venworks Canvas version 1.0.4 or newer, then this theme. Enable exactly one VWHUD theme. The Canvas Example is not required.

This package contains VWHUD-owned consumer files under Canvas's isolated consumer directory. It does not include or copy the Canvas framework. Do not combine it with an earlier standalone VWHUD HUD replacement.

# Customization

This Creation provides the shipped preconfigured theme. Xbox and PlayStation 5 do not use the Nexus PC loose-file customization workflow. PC mod authors can find the VWHUD theme paths, stable CSS classes, editable files, and Canvas documentation links here:

https://github.com/monster-cookie/venworks-honkcore-ta-ui/blob/master/docs/CUSTOMIZING_THEMES.md

# Validation status

Minimalist remains a reduced visual composition. PC and console packages are built separately; large-HUD, ultrawide, sustained-update, and exact-package platform feedback remain valuable until final acceptance is recorded.
