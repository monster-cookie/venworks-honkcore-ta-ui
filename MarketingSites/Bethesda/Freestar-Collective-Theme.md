# Overview

Venworks Customizable HUD - Freestar Collective Theme presents the full tactical HUD with the Freestar Collective visual style. It is an HTML/CSS/SVG consumer rendered by Venworks Canvas and retains its own plugin, status-effect catalog, and theme resources.

# Features

- Helmet frame, compass heading, threat state, and compact paged status effects.
- Player health, oxygen, CO2, boost, carry mass, currency, time, and progression information.
- Equipment rail for favorites, weapon, ammunition, explosive, and power information.
- Environment panels for location, time, gravity, suit protection, and active hazard categories.
- Tracked objective, acquired-contact radar, and forward scanner presentation.
- Bethesda's current vehicle-exit glyph through Canvas's native symbol adapter.

# Requirements and installation

Install Venworks Core Library, then Venworks Canvas, then this theme. Enable exactly one VWHUD theme. The Canvas Example is not required.

This package contains VWHUD-owned consumer files under Canvas's isolated consumer directory. It does not include or copy the Canvas framework. Do not combine it with an earlier standalone VWHUD HUD replacement.

# Validation status

PC and console packages are built separately. Large-HUD, ultrawide, sustained-update, and exact-package platform feedback remain valuable until final acceptance is recorded.
