# Overview

Venworks Customizable HUD - Venworks Theme is a full tactical helmet HUD in the blue Venworks colors. It runs with Venworks Canvas and keeps its own plugin.

# Features

- Compass, threat warning, and a short row of status icons.
- Health, oxygen, CO2, boost, carry weight, credits, local time, and level.
- An equipment rail for favorites, your weapon, ammo, explosives, and powers.
- Where you are, the local clock, gravity, suit protection, and hazards.
- Your tracked mission, a radar of known contacts, and a scanner view when you scan.
- The game's own button prompt when you are ready to leave a vehicle.

# Requirements and installation

Install Venworks Core Library 2.1.8 or newer, then Venworks Canvas 1.0.4 or newer, then this theme. Enable one Venworks HUD theme. You do not need the Canvas Example.

Remove any older copy of this HUD first. This theme does not include Canvas itself. Canvas is a separate install.

# Customization

Xbox and PlayStation use this theme as published.

On PC, you can recolor, move, or hide panels. The guide is here:

https://github.com/monster-cookie/venworks-honkcore-ta-ui/blob/master/docs/CUSTOMIZING_THEMES.md

To hide or remove the equipment rail on PC:

https://github.com/monster-cookie/venworks-honkcore-ta-ui/blob/master/docs/REMOVING_EQUIPRAIL.md

# Good to know

This theme is still in beta. Notes from large HUD mode, ultrawide screens, and consoles help a lot.

The radar shows contacts the game already knows about.
